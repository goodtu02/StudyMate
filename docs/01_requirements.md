# 요구사항 분석 (Requirements Analysis)

## 1. 사용자 문제 정의

학생 및 개인 학습자들이 과제, 학습 계획, 과목 및 개인 학습 목표를 관리해야 하는 상황에서, 오늘 무엇을 공부해야 하는지 놓치기 쉽고, 공부 후 짧은 회고를 작성하는 습관을 유지하기 어렵습니다.

StudyMate는 이 문제를 해결하기 위해, 사용자가 학습 태스크를 등록하고, 오늘의 학습 일정을 확인하고, 태스크를 완료 표시하고, 짧은 회고를 작성할 수 있는 간단한 웹 애플리케이션을 제공합니다.

## 4. 범위 정의

### In Scope
- 학습 태스크 CRUD
- 오늘 태스크 필터/강조
- 완료 상태 토글
- 회고 작성 및 AI 제안
- 입력 검증
- 테스트 케이스 작성/실행
- GitHub 프로세스 증거 기록
- 스크린샷 캡처

### Out of Scope
- 사용자 로그인/회원가입
- 다중 사용자 동기화
- 외부 캘린더 연동
- 네이티브 모바일 앱
- 복잡한 통계 대시보드

---

## 5. 우선순위 분류 (MoSCoW)

- **Must Have**: 태스크 생성, 목록 조회, 오늘 태스크 확인, 완료 토글, 회고 작성, 데이터 영속성, 입력 검증
- **Should Have**: 태스크 편집/삭제, 카테고리 태그, AI 회고 제안, 반응형 레이아웃
- **Could Have**: 완료율 표시, 날짜 필터, 다크 모드
- **Won't Have**: 로그인, 서버 기반 사용자 관리, 팀 협업
