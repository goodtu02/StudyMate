## Summary

Add a reflection text area to each study task card. The user can write, edit, and save a free-text reflection. The reflection is stored as a field of the StudyTask entity in localStorage and persists across sessions.

---

## Technical Context

**Language/Version**: TypeScript (React)  
**Primary Dependencies**: React 18+ (extends Feature 001 components)  
**Storage**: localStorage, key: `studymate.tasks` (reflection stored in StudyTask.reflection field)  
**Testing**: Manual (TC-006 per spec.md §12.3); optional Vitest  
**Target Platform**: Desktop web browser; basic mobile responsive  
**Project Type**: Extension to existing SPA (Feature 001)  
**Performance Goals**: No additional performance requirements  
**Constraints**: Depends on Feature 001 (Core Study Task Management) being complete  
**Scale/Scope**: Per-task reflection; no separate storage key needed
