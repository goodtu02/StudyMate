# Implementation Plan: AI Reflection Suggestion

**Branch**: `003-ai-reflection-suggestion` | **Date**: 2026-05-07 | **Spec**: [spec.md](./spec.md)  
**Input**: Feature specification from `/specs/003-featurename-ai-reflection/spec.md`

---

## Summary

Add an "AI Suggestion" button to the reflection area. When clicked, a mock AI function generates a template-based reflection suggestion using the task's title, category, and memo. The suggestion is placed into the reflection input field for the user to edit before saving. A real external AI API (e.g., Gemini, OpenAI) can optionally replace the mock.

---

## Technical Context

**Language/Version**: TypeScript (React)  
**Primary Dependencies**: React 18+ (extends Feature 002); optional: Gemini API or OpenAI SDK  
**Storage**: No new storage — suggestion populates the reflection textarea (Feature 002)  
**Testing**: Manual (TC-010 per spec.md §12.3)  
**Target Platform**: Desktop web browser  
**Project Type**: Extension to existing SPA (Features 001 + 002)  
**Performance Goals**: Mock function is synchronous; real API should respond in <5 seconds  
**Constraints**: API keys MUST use `.env` and `.gitignore`; mock is default  
**Scale/Scope**: Per-task, on-demand suggestion
