# StudyMate

StudyMate is a modern web application built with React, TypeScript, and Vite designed to help you manage your study tasks, reflect on your learning, and get AI-powered study suggestions.

## Features

- **Task Management**: Create, edit, delete, and complete study tasks.
- **Study Reflection**: Write reflections on completed tasks.
- **AI Suggestion**: Get AI-generated reflections based on your tasks.
- **Local Persistence**: All your data is saved locally in your browser.

## Development Setup

1. Install dependencies:
   ```bash
   npm install
   ```
2. Start the development server:
   ```bash
   npm run dev
   ```
3. Run tests:
   ```bash
   npm run test
   ```

## Technologies

- React 19
- TypeScript
- Vite
- Vitest & React Testing Library (for testing)
